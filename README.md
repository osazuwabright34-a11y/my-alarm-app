# My Alarm App

A cross-platform alarm application built with Flutter. This starter provides a solid foundation for creating, managing, and scheduling alarms with local notifications.

## Features (MVP)

- Create, view, and delete alarms
- Set time and optional label
- Basic recurrence support (daily)
- Local notifications using `flutter_local_notifications`
- Persistent storage of alarms
- Clean, modern Material 3 UI

## Prerequisites

- Flutter SDK (stable channel, 3.22 or later recommended)
- Dart SDK (included with Flutter)
- Android Studio / Xcode for platform builds
- A physical device or emulator for testing notifications (notifications behave differently on simulators)
